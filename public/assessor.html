Submit Assessment or Vetting Reports

Select the report type and receiving department. If you received a secure assignment email, use the single assignment workspace link in that email to download assigned works and submit each report. Use this public form only for manual or exceptional submissions not created through an assignment.

Report Type and Department

Fresh dissertation assignments use Assessment Report. Vetting is normally used for revised submissions.

Assessor details

The portal creates one student and upload section for each report.

Students and accompanying documents

Complete each work separately. Every student must have one report, one claim form and one score sheet. The reviewed dissertation upload is optional.

All work sections are stored together under this assessor in the departmental admin portal.
